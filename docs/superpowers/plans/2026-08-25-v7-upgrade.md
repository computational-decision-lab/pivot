# PIVOT V7 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** Add auditable operator-shift theory, PIVOT-VOI, validity-aware adaptive experiments, and a reproducible V7 submission pipeline while preserving V9 exactly.

**Architecture:** Keep the existing `pivot` contracts and `improve_x` platform as the transition data plane. Add theory, acquisition, research-state, validity, and benchmark modules as focused layers. New V7 experiments write versioned outputs beside, never over, V9 artifacts.

**Tech Stack:** Python 3.10, NumPy, PyYAML, pytest, Ruff, mypy, LaTeX/latexmk.

## Global Constraints

- Preserve `archive/submission_v9` and never overwrite V9 outputs.
- Use paired rollouts and transition-level estimands for every new result.
- Use development/validation/confirmatory separation and hierarchical uncertainty.
- Classify every experiment as `IMPLEMENTATION_FAILURE`, `DESIGN_INVALID`, `UNDERPOWERED`, `HYPOTHESIS_SUPPORTED`, or `HYPOTHESIS_NOT_SUPPORTED`.
- Preserve finance as `FROZEN_NEGATIVE`; do not tune it for reversal.
- No new external dependency without a reproducible lock/version rationale.
