# 研究问题与理论

> 本文是中文主说明，英文科研文档仍是原文依据。若中文与英文有冲突，以
> [research question](../research_question.md)、[theory notes](../theory_notes.md)、
> [estimands](../estimands.md)、[claim boundary](../claim_boundary.md) 及注册协议为准。

## 1. 一句话定义

PIVOT 研究的是**自我改进更新的保真度**（*Improvement Fidelity*）：一个代理把
当前策略 `pi` 更新为候选策略 `pi'` 后，在便宜的代理评估器（proxy/verifier）中看起来
有进步，部署到会响应策略的环境后是否仍有进步。

研究对象是转移（transition），不是单个策略的静态分数：

```text
tau = (pi, pi')
```

核心失败事件是**改进反转**（*Improvement Reversal, IR*）：

```text
Delta_proxy > 0  且  Delta_true < 0
```

战略层的更强失败事件是**战略改进反转**（*Strategic Improvement Reversal, SIR*）：

```text
Delta_actor > 0  且  Delta_strategic < 0
```

因此项目不是授权、拒绝、执行路线或交易策略生成器。它只判断“这次学习更新是否
仍然是学习进步”，并把失真来源拆成代理误差、部署后的机械响应和竞争者响应。

## 2. 符号和世界层

设 `pi_t` 是第 `t` 轮 incumbent，`pi'_{t,j}` 是改进算子 `A` 从 incumbent 生成的
第 `j` 个候选，候选集合记为 `C_t`。`J` 是给定策略和世界下的期望目标值，所有
`Delta` 都是候选减 incumbent：

```text
Delta_V(t,j) = J_V(pi'_{t,j}) - J_V(pi_t)
Delta_*(t,j) = J_*(pi'_{t,j}) - J_*(pi_t)
```

代码把部署真值拆成三个可审计的世界层：

| 世界 | 数学对象 | 代码中的含义 | 用途 |
| --- | --- | --- | --- |
| Observer / World 0 | `J_V` 或 `J_direct` | 固定、便宜的 proxy；无策略诱发响应 | 产生 `delta_proxy`，作为低成本基准 |
| Actor / World 1 | `J(pi; M[pi])` | 部署策略改变环境后的机械响应 | 产生 `delta_actor` / `delta_true`，检验 IR |
| Strategic / World 2 | `J_i(pi_i, BR_-i(pi_i))` | 对手或其他代理根据策略作响应 | 产生 `delta_strategic`，检验 SIR |

在能识别反事实时，进一步定义：

```text
Delta_direct = J(pi'; M[pi]) - J(pi; M[pi])
mechanical_effect = Delta_actor - Delta_direct
competition_effect = Delta_strategic - Delta_actor
```

`direct`、`actor`、`strategic` 是估计对象，不自动等同于现实世界真值；缺失反事实
必须保留为 `null`，不能用另一层静默填充。

## 3. 六个理论结果及其边界

下列结果是论文和注册实验允许引用的理论范围。每项都明确“条件、结论、证据级别”，
避免把模拟观察写成定理。

### T1. 全局价值保真度是充分条件

**Assumption / 假设**

对所有策略有统一误差上界：

```text
sup_pi |J_V(pi) - J_*(pi)| <= epsilon
```

**Proposition / 命题**

```text
|Delta_V - Delta_*| <= 2 * epsilon
```

如果更新不是平局且 `|Delta_*| > 2 epsilon`，则 proxy 与部署层符号一致。

**Proof sketch / 证明要点**

将差值写成两个点误差之差：
`(J_V(pi')-J_*(pi')) - (J_V(pi)-J_*(pi))`，再用三角不等式。

**边界**

这是充分而非必要条件；一个与策略无关的大常数偏移会让绝对价值误差很大，
但在成对差分中完全抵消。实现和单元测试可验证该代数性质，不能据此声称现实
环境一定满足统一 `epsilon`。

### T2. 全局保真度盲区（构造性反例）

**Statement / 陈述**

对任意 `epsilon > 0`，存在有限策略族、proxy、策略分布和更新算子，使策略层
MAE 与 Spearman 排名误差都小于 `epsilon`，但在算子诱导的转移分布上 `IRR=1`、
`ISC=0`。

**Construction / 构造**

令真实值为 `J_*(i)=i/(n-1)`，proxy 只交换一个相邻策略对。随着 `n` 增大，
全局 MAE 与排名误差趋近零；若更新算子只抽取这对交换的有向转移，就得到
proxy 正、部署负的必然反转。

**边界**

可声称“有限、采样或分布外的全局排名指标不蕴含局部更新符号一致性”。不能把
“exact pairwise ranking over the same complete deployment policy set”说成不足；
若完整集合中的每一对顺序都精确保持，非平局差分符号按定义保持。

### T3. 算子分布偏移界（Operator Shift Bound）

令 `P` 为校准转移分布，`Q_A` 为更新算子 `A` 诱导的分布，且 `Q_A << P`，
密度比为 `w=dQ_A/dP`。令非负损失
`ell(tau)=L(Delta_V, Delta_*)`，则：

```text
IF(V, A; L) = E_QA[ell]
               <= sqrt(E_P[ell^2]) * sqrt(1 + chi^2(Q_A || P))
```

**Proof sketch**：换测度后用 Cauchy--Schwarz，且 `E_P[w^2]=1+chi^2`。

**解释**

即使校准集上的误差小，更新算子集中到校准分布尾部时，算子相对的
Improvement Fidelity 也可能变差。实验需记录 `Q_A` 的权重、有效样本量或分布
偏移诊断；该界是统计上界，不是因果效果估计。

### T4. 响应--更新足迹界（Response--Footprint Bound）

定义更新足迹 `d(pi,pi')`，环境状态/响应距离 `D`。若满足：

```text
D(M[pi'], M[pi]) <= L_M * d(pi, pi')
```

且价值泛函关于世界参数是 `L_J`-Lipschitz，则：

```text
|Delta_actor - Delta_direct| <= L_J * L_M * d(pi, pi')
```

**Proof sketch**：`direct` 与 `actor` 的 incumbent 项都在 `M[pi]` 上，抵消后只剩
候选项；对该项应用 Lipschitz 条件。

**实现边界**

`compute_update_footprint` 当前提供参数 L2 距离、平均 action shift、最大 shift、
entropy change、support expansion 等可审计分量。`L_M`、`L_J` 与常数必须从所选
环境和目标的正式假设或实验校准得到；代码不会硬编码一个未证明的通用常数。
若环境违反 Lipschitz 区域，这是边界发现，不是应隐藏的实现失败。

### 战略敏感度：经验扩展，不是已证明的全局界

竞争者响应可用下式描述：

```text
S_-i = D(BR_-i(pi_i'), BR_-i(pi_i)) / (d(pi_i', pi_i) + epsilon)
```

这里 `BR_-i` 是在指定干预模型下其他代理的最佳响应或其近似，`epsilon` 仅用于
数值稳定。E8 的任务是检验高 `S_-i` 是否与 SIRR 相关，以及小的 focal update 是否
会触发过大的竞争者改变。该量必须连同对手更新规则、干预、置信区间和随机种子报告；
它是探索性经验诊断，不是 T4 的前提，也不推出竞争者最佳响应全局 Lipschitz。

### T5. 差分误差下的决策保持

对候选 `i,j`，真实差距为 `m=Delta_{*,i}-Delta_{*,j}>0`。若两者估计误差均小于
`m/2`，则估计排序不变。

这是 PIVOT 的直接动机：目标不是恢复每个策略的绝对价值，而是保护本轮候选池中
会改变选择的局部排序。该命题只需三角不等式，不能推出 PIVOT 在所有任务上优于
所有基线。

### T6. 有限样本最佳更新识别

若每个候选的成对 rollout 差分是 `sigma`-sub-Gaussian，最佳候选与次佳候选真实
差距至少为 `m>0`，每个候选使用 `n` 次成对 rollout，则错误选择概率满足：

```text
P(wrong selection) <= (K - 1) * exp(-n * m^2 / (4 * sigma^2))
```

要使错误概率不超过 `delta`，充分的样本数为：

```text
n >= 4 * sigma^2 / m^2 * log((K - 1) / delta)
```

该结论依赖独立、成对且次高斯的 rollout 差分；重尾金融数据或自适应停止时，
必须报告实际 bootstrap/置信区间和假设是否成立。

## 4. 指标和统计对象

所有指标按 transition row 计算，缺失层不插补：

| 指标 | 定义 | 解释 |
| --- | --- | --- |
| `IDE` | `E[abs(Delta_proxy - Delta_true)]` | 更新值误差 |
| `ISC` | `P(sign(proxy)=sign(true))`（排除平局） | 更新方向一致性 |
| `IRR` | `P(Delta_true<0 \| Delta_proxy>0)` | 代理误报“有进步”的比例 |
| `SIRR` | `P(Delta_strategic<0 \| Delta_actor>0)` | 竞争响应造成的反转 |
| `MTR` | `Delta_true/Delta_proxy`，仅在 `abs(proxy)>tau_mtr` | 改进倍数，分母不稳时为 null |
| `ISR` | `max_j Delta_true,j - Delta_true,selected` | 本轮选择遗憾 |
| `CTI` | `sum_t Delta_true,selected,t` | 轨迹累计真实改进 |

符号平局由 `tau_sign` 定义，平局计数单独报告，不能强行归入正负。预算比较必须
固定候选池、环境和 HF 查询预算；成本包括 HF transitions、paired rollouts、环境
步数、模拟器调用和可定义时的计算成本。

## 5. 证据层级与可引用范围

- **形式证明**：只能支持在明确假设下的代数界和概率界。
- **受控环境**：可支持机制级的反转、足迹--响应关系和预算对照；不能自动外推
  到真实市场。
- **ImprovementBench**：在冻结 transition rows 上测 sign/ranking/explanation，
  不等于外部有效性。
- **金融数据**：当前是观察性或边界诊断；没有干预设计就不能识别内生补单、
  竞争适应或因果市场冲击。
- **IMPROVE-X/PIVOT-X 实现**：算法可运行不等于优越性成立，必须和同预算的
  Random HF、Top Proxy、Uncertainty 等基线比较。

可引用的项目边界集中在 `docs/claim_boundary.md`。论文、报告和新实验都必须
沿用 `DEV`、`UNDERPOWERED`、`NOT_RUN`、`BLOCKED` 等终止状态，不得将其改写为
确认性结果。
