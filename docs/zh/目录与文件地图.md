# PIVOT 目录与文件地图

本页解释“去哪里找什么”。现有目录不移动，因为运行脚本、论文源文件、结果清单和哈希记录依赖既定路径。

## 顶层目录

| 路径 | 职责 | 新同事首先看什么 |
| --- | --- | --- |
| `src/pivot/` | 研究核心：策略、transition、世界、评估、footprint、指标、迁移和理论 | `core/transition.py`、`evaluation/paired.py`、`acquisition/pivot_voi.py` |
| `src/pivot_core/` | 稳定、与 agent 无关的公开接口 | `__init__.py` |
| `src/pivot_inspect/` | 外部执行边界的稳定接口 | `__init__.py` |
| `src/improve_x/` | IMPROVE-X 平台：轨迹、基准、算子、失败分类、PIVOT-X | `core/`、`benchmark/`、`acquisition/` |
| `experiments/` | 历史 P0-P9、V9、V10、V15 的实验 runner 和审计器 | `v9/`、`v15/` |
| `configs/` | 受控、注册、金融、理论、ImprovementBench 和 V15 配置 | 与 runner 同名配置 |
| `tests/` | 单元和集成测试 | `tests/unit/`、`tests/integration/` |
| `results/` | 运行结果，按版本/实验隔离 | `results/v9/`、`results/v15/` |
| `artifacts/` | 验证、汇总和构建产物 | `artifacts/v9/`、`artifacts/v15/` |
| `figures/`、`tables/` | 图表源、渲染和数据表 | `figures/v15/` |
| `paper/` | 当前 ICLR 2027 投稿源、补充材料和发布构件 | `paper/` |
| `release/v15/` | 脱敏匿名发布包 | `README.md`、`submission_verification.json` |
| `snapshot/`、`archive/` | 历史基线和旧提交归档 | 仅在追溯或回退时使用 |

## 文档优先级

状态判断按以下顺序：

1. 当前版本的 `docs/archive/v15/V15_FINAL_REPORT.md`、`docs/archive/v15/V15_IMPLEMENTATION_MATRIX.md`、`docs/archive/v15/V15_REPRODUCIBILITY_AUDIT.md`。
2. `release/v15/submission_verification.json` 和 `release/v15/confirmatory_lock.json`。
3. 对应实验目录中的 `scientific_decision.json`、`manifest.json` 和 canonical 结果。
4. `research/research_state.json`、`docs/implementation-status.md` 等历史台账仅用于追溯，不能覆盖 V15 当前状态。

论文叙事以 `paper/main.tex` 为当前入口；旧工作论文材料已归档至 `paper/archive/working-paper/`。

## 关键源码链路

```text
Policy
  -> PolicyTransition
  -> PairedEvaluator
  -> Footprint / transfer features
  -> Bayesian delta posterior
  -> PIVOT-VOI acquisition
  -> run_pivot_round / run_pivot_voi_round
  -> transition artifact / canonical result
```

对应文件：

- `src/pivot/core/policy.py`
- `src/pivot/core/transition.py`
- `src/pivot/evaluation/paired.py`
- `src/pivot/footprint/generic.py`
- `src/pivot/acquisition/pivot_voi.py`
- `src/pivot/algorithms/pivot.py`

## 关键实验链路

```text
configs/<version>/<experiment>.yaml
  -> experiments/<version>/run*.py
  -> results/<version>/<run>/
  -> manifest + scientific_decision + tables/figures
  -> audit / paper / release
```

任何新结果都应保留原始行、配置哈希、代码提交、运行状态和失败记录；不要只提交一张汇总表。
