# PIVOT 项目入口与当前状态

> 更新时间：2026-09-15

## 一句话说明

PIVOT（Paired Interventional Validation of Optimization Transitions）研究自我改进系统的**更新**是否在部署后仍然有效。研究对象是一次策略更新 `pi -> pi'`，而不是单独比较两个静态策略。

IMPROVE-X 是同一研究问题的平台化实现，提供多轮改进轨迹、ImprovementBench、失败分类和 PIVOT-X 决策保留指标。它是工程平台层，不代表额外的确认性外部证据。

## 现在可以说什么

- 可以说：核心代码、数据契约、理论受控检查、图表、论文构建和发布审计已经落地。
- 可以说：V9 的注册受控实验在各自的有限机制和配置范围内产生了已记录的支持或不支持结果。
- 可以说：V15 的外部运行时已固定，DEV 阶段验证了执行接口、配对沙箱、任务平面和结果契约。
