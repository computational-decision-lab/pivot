# Frozen-State Matched Selector Follow-Up

This post-review auxiliary experiment isolates the query-allocation step from
the trajectories in the v3c closed loop. It is specified after the v3c result
and is not a replacement for, or pooled with, the v3c confirmation. Its purpose
is diagnostic: compare selectors at identical decision states and panels.

## Locked protocol

- Controlled `PerformativeWorld`, one decision per root, four candidates, two
  sequential paired HF queries, posterior-mean terminal selection including
  the incumbent.
- Methods: PIVOT-KG-Loop-v3c, IVR-Online-v3c, Top-Proxy-Online-v3c. All use
  the sealed v3c contextual calibration model; no cross-method or cross-round
  coefficient update is allowed.
- Use 120 fresh roots per low/medium/high response regime (`0.35/0.60/0.85`),
  with root blocks `990000`, `1000000`, and `1010000`. No root may overlap the
  calibration, v3c development, or v3c confirmation blocks.
- Every selector at a given root receives the same initial pressure, incumbent
  `{intensity: 0.18, bias: 0.0}`, candidate panel, proxy values, calibration
  model, query budget, query seed schedule, evaluation seeds, and terminal
  rule. The world state is frozen; no deployment is carried into another
  decision.
- Method-specific acquisition chooses both queries sequentially, conditioning
  the latent posterior with the same positive observation variance used by
  v3c. HF values are generated by the controlled world under common root,
  round-zero, and candidate-id seeds.

## Outcomes and analysis

Primary outcome: paired-root ISR, with baseline-minus-PIVOT contrasts (positive
favors PIVOT). Secondary outcome: paired-root deployment return, with
PIVOT-minus-baseline contrasts (positive favors PIVOT). Report each regime and
all roots, 10,000 paired-root bootstrap intervals, and 100,000 sign-flip tests;
apply Holm over the six regime-by-baseline ISR contrasts. Also report selected
candidate, query IDs, panel hash, and exact counts. No response regime or
contrast is selected after observing results.

Because this auxiliary protocol follows earlier v1-v4a and v3c results, its
statistics are a separate post-review diagnostic and do not extend the v3c
confirmatory claim or correct for the preceding variant search.
