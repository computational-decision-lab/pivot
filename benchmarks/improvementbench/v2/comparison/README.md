# IMPROVE-X v2 Matched-Budget Comparison

This subdirectory is a controlled diagnostic generated by
`scripts/run_improve_x_comparison.py`. It compares `proxy_only`, `random_hf`,
`top_proxy_hf`, and `pivot_x` over three sequential rounds on the frozen test
seed. Train-split strategic rows calibrate the differential correction model;
the other methods receive the same two high-fidelity queries per round when
applicable. Every candidate and query decision is retained.

```bash
.venv/bin/python scripts/run_improve_x_comparison.py \
  --config configs/improve_x/comparison.yaml \
  --benchmark benchmarks/improvementbench/v2 \
  --output /tmp/improve-x-comparison
```

`manifest.json` binds the output files to the benchmark manifest and source
commit. The result is a controlled engineering diagnostic, not a claim of
general PIVOT-X superiority or external causal market validity.
