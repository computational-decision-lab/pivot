# E3b Development: Short-Horizon Direct Replay Proxy

All five construct-validity gates pass on 10 paired `(environment, seed)` units.
The observer uses a frozen 12-step direct replay with candidate actions and
replay opponents; actor evaluation runs the full MPE2 deployment horizon.
This is development evidence only and is underpowered under the registered
trajectory-level CTI rule. The prior discrete-target confirmatory attempt is
retained separately as `e3b-confirmatory-invalid-proxy`.
