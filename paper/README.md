# PIVOT ICLR 2027 Submission Package

This directory is the canonical anonymous ICLR 2027 submission candidate for
*When Better Gets Worse: Improvement Fidelity for Self-Improving Agents in
Adaptive Worlds*.

## Build and audit

From the repository root, install the Highway dependency lock with Python
3.12, then run:

```bash
python3.12 -m venv .venv-highway
.venv-highway/bin/python -m pip install -r reproduction/highway/requirements-lock.txt
PIVOT_PYTHON="$PWD/.venv-highway/bin/python" bash paper/build.sh
```

This recomputes the Highway results from both hash-checked seed cohorts,
compiles the current manuscript, builds the anonymous supplement, and checks
the PDF and archive. It needs TeX Live (including texlive-science for algorithm/algorithmic), latexmk, and Poppler. For an extracted
supplement, use `bash paper/build_frozen.sh` with the same `PIVOT_PYTHON`.
No private cloud directories or credentials are needed for that build.
See `reproduction/highway/README.md` for the frozen simulator rerun commands,
logical-versus-physical budget accounting, and the smoke-exposure limitation.

The local audit reports the PDF, page, source, reference, anonymity, and
supplement checks separately from author-managed submission gates. This
describes the anonymous package, not a completed OpenReview action: profile,
author metadata, conflicts, quota, AI-use form disclosure, and final upload
remain manual author actions. No causal market or equilibrium claim is made.

For a paper-only rebuild, use `paper/build_frozen.sh`. Historical V15 report
commands describe their own experiment snapshots and are not the current
manuscript build entry point.

The frozen V9 confirmatory results are generated by the unified runner under
`results/v9` and copied into the anonymous supplement by
`scripts/build_iclr_supplement.py`. E2C, E3C, E4C, E5C, and E7C retain their
scientific terminal states, including the powered E4C null and the non-uniform
E3C baseline comparisons. E3C combines the two new controlled worlds with the
previously powered Farama MPE2 null, which remains frozen and is not relabeled.

The controlled E4 spotlight diagnostic is reproducible with:

```bash
.venv/bin/python experiments/e4_value_vs_improvement.py \
  --config configs/sweeps/e4_value_vs_improvement.yaml \
  --output /tmp/pivot-e4-value-vs-improvement
```

It compares an evaluator with slightly better isolated policy-value accuracy
against one with exact paired deltas. The result is intentionally labelled a
controlled estimand diagnostic, not a universal method claim.

The V6 theorem checks are reproducible with:

```bash
.venv/bin/python experiments/e10_theory_empirical.py \\
  --config configs/theory/v6_empirical.yaml \\
  --output results/theory/e10-theory-empirical
```

The registered output is included in the supplementary archive under
`results/theory`; it checks the Global Fidelity Blindness construction and the
exact response-footprint bound without making a causal market claim.

The architecture figure is generated from the pinned OpenTikZ
`system-block-diagram` template (commit
`359befbf8e8af7ce08e7e387b2c2a198e0ca735d`). The checkout is installed and
verified without modifying the upstream repository:

```bash
.venv/bin/python scripts/bootstrap_opentikz.py
.venv/bin/python scripts/build_opentikz_architecture.py
```

The lock file records the template and reference-file SHA-256 values. OpenTikZ
code is MIT-licensed and its template content is CC0-1.0; the adapted source
and metadata remain in the curated figure bundle for anonymous reproducibility.

The full V15 task manifest and lock history are sealed local inputs and are not
included in the public source release. The supplementary archive carries only
their hash-indexed, redacted summaries; no confirmatory run can be reconstructed
from the public package without the separately authorized sealed inputs.

## Directory policy

`paper/` is the single active manuscript surface. It contains the submission
source, figures, build outputs, verification records, and supplementary package.
The former working-paper surface is retained under
`paper/archive/working-paper/` for provenance only and is not used by the
current build or release workflow.
